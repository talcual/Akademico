## Fullstack Avanzado

Este directorio contiene prácticas y ejercicios de **desarrollo fullstack avanzado**.

### Objetivo

Aplicar buenas prácticas para construir aplicaciones modernas, escalables y mantenibles, integrando frontend, backend y despliegue.

### Actividades básicas que se realizarán

- Diseño de arquitectura cliente-servidor.
- Creación de APIs REST (y fundamentos de GraphQL).
- Integración de frontend con backend.
- Manejo de autenticación y autorización (JWT, roles, sesiones).
- Conexión y modelado de bases de datos SQL/NoSQL.
- Validación de datos y manejo centralizado de errores.
- Implementación de pruebas básicas (unitarias e integración).
- Uso de variables de entorno y configuración por ambientes.
- Contenerización básica con Docker.
- Despliegue inicial en entornos cloud.

### Resultado esperado

Al finalizar, se contará con una base práctica para desarrollar y publicar proyectos fullstack con enfoque profesional.
